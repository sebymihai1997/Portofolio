Digital Scale

   This was a university team project completed by a group of three. Our work highly impressed the professor, as we were the only team that managed to deliver a polished device that looked and functioned close to a production-ready prototype.

   We divided the responsibilities based on each member's core strengths. I took charge of the electronic and technical development, which involved component sourcing, PCB design, and hands-on soldering. One teammate focused on the software development, while the third member handled the industrial/enclosure design and acted as the project manager.

   Continuous communication was essential to build a stable and reliable device. Every component I selected came with manufacturer specifications, which the software engineer needed to write highly optimized code tailored to the hardware. At the same time, the enclosure designer required the exact physical dimensions of the components and the PCB layout to ensure a perfect fit inside the casing and to create a precise cutout for the display.

   For this project we used a Load Cell as the weight sensor which can measure up to 10 Kg. To amplify the signal and convert it to digital, we used an HX711 ADC (Analog-to-Digital Converter). The signal processing was handled by an Arduino UNO, and the weight display was managed by an LCD 16x2.

   Upon startup, the device executes a calibration routine that requires placing a 100g reference weight on the scale. Once this calibration process is complete, a confirmation message is displayed on the screen, and the device is ready for use.
